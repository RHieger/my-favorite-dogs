# My Favorite Dogs v3.0

In Version 2.5, last developd approximately 10 months ago, the aim
was to explore applying regular expressions to the existing code
base in order to replace segments of a string.

Additionally, other functionality such as auto-correcting user
input with case folding user input to uppercase using JavaScript
string manipulation.

In Version 3.0, by contrast, the aim is to create a comprehensive
re-design of the program from top to bottom, adjusting and
improving UX and UI. In addition, another primary aim in this
iteration is to harden code to anticipte possible errors in entry
by end users.
